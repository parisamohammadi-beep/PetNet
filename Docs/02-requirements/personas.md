## ۲. پرسونا ۱ — صاحب پت (کاربر اصلی)

### مشخصات دموگرافیک
| ویژگی | مقدار |
|--------|-------|
| نام | سارا همتی |
| سن | 28 سال |
| جنسیت | زن |
| شغل | کارمند شرکت خصوصی |
| محل زندگی | تهران |
| تحصیلات |کارشناسی ارشد |
| مهارت فنی | متوسط رو به بالا |
| وضعیت تأهل | مجرد |

### نقل‌قول
> «من میلو رو مثل بچه‌م دوست دارم. فقط می‌خوام مطمئن باشم بهترین مراقبت رو براش دارم، ولی وقت و انرژی برای گشتن تو اینترنت را ندارم»

### اهداف
- پیدا کردن اطلاعات دقیق و قابل اعتماد درباره نگهداری، تغذیه و سلامت گربه‌اش
- پیدا کردن دامپزشک نزدیک و معتبر
- خرید آنلاین لوازم مورد نیاز پت
- ارتباط با دیگر صاحبان پت و تبادل تجربه


### دردها
- اطلاعات متناقض در اینترنت درباره نگهداری پت
- پیدا نکردن دامپزشک خوب و در دسترس در ساعات اضطراری
- گرون بودن لوازم و پیدا نکردن تخفیف مناسب
- نگرانی از تنها گذاشتن گربه در سفرهای کاری

### نیازها
-  بخش مقالات تخصصی و تأییدشده توسط دامپزشکان
- سیستم نوبت‌دهی آنلاین دامپزشکی
- فروشگاه آنلاین با ارسال سریع و تخفیف
- انجمن گفتگو برای صاحبان پت
- یادآور واکسیناسیون و چکاپ

### سناریوی استفاده
> از موبایل وارد سایت می‌شه
> روی بخش «دامپزشکان» کلیک می‌کنه
> فیلتر می‌ذاره: تهران، تخصص گربه، نوبت امروز
> پروفایل دکتر امیر رضایی رو می‌بینه، نظرات بقیه رو می‌خونه
> دکمه «رزرو نوبت آنلاین» رو می‌زنه و ساعت ۶ عصر رو انتخاب می‌کنه

## ۳. پرسونا ۲ — امیر رضایی (دامپزشک)

### مشخصات دموگرافیک
| ویژگی | مقدار |
|--------|-------|
| نام | امیر رضایی |
| سن | 42 سال |
| جنسیت | مرد |
| شغل | دامپزشک عمومی |
| محل زندگی | تهران |
| تحصیلات | دکترای دامپزشکی |
| مهارت فنی | بالا |
| وضعیت تأهل | متأهل، دو فرزند |

### نقل‌قول
> «وقت من باید صرف درمان بشه، نه پاسخ دادن به تلفن‌های نوبت‌دهی و گم کردن پرونده‌های کاغذی.»

### اهداف
- مدیریت نوبت‌ها و پرونده بیماران به صورت دیجیتال
- به اشتراک گذاشتن دانش و مقالات تخصصی
- ارتباط با صاحبان پت برای پیگیری درمان

### دردها
-  نداشتن سیستم منظم برای مدیریت نوبت‌ها (فعلاً تلفنی و دستی)
- صاحبان پت که دیر مراجعه می‌کنند یا توصیه‌ها را جدی نمی‌گیرند
- عدم دسترسی به تاریخچه پزشکی کامل بیمار
- هزینه بالای تبلیغات سنتی برای جذب بیمار

### نیازها
-  پنل مدیریت نوبت و پرونده بیمار
- پروفایل عمومی برای معرفی تخصص و دریافت نظرات
- امکان انتشار مقاله و ویدیو آموزشی
- سیستم یادآوری خودکار برای واکسیناسیون و چکاپ

### سناریوی استفاده
> وارد پنل دامپزشکان می‌شه
> پروانه مطب و تخصصش رو بارگذاری می‌کنه
> در قسمت پروفایل : ساعات کاری در کلینیک و اطلاعات خودش رو وارد می‌کنه
> سیستم نوبت‌دهی آنلاین رو فعال می‌کنه
> یک کاربر جدید از سایت براش نوبت رزرو می‌کنه
> دکتر پرونده بیمار رو در پنل می‌بینه و یادداشت درمان ثبت می‌کنه
> یک مقاله آموزشی درباره «واکسیناسیون سگ‌ها» منتشر می‌کنه
> نظرات بیماران رو می‌خونه و به سوالاتشون پاسخ می‌ده

## ۴. پرسونا ۳ — مریم کریمی ( صاحب پت شاپ )

### مشخصات دموگرافیک
| ویژگی | مقدار |
|--------|-------|
| نام | مریم کریمی |
| سن | 37 سال |
| جنسیت | زن |
| شغل | مالک کلینیک پت نت آنلاین و فیزیکی |
| محل زندگی | تهران |
| تحصیلات | دکترای دامپزشکی |
| مهارت فنی | بالا |

### نقل‌قول
> «من عاشق کارم هستم، ولی رقابت با برندهای بزرگ واقعاً سخته. یه پلتفرم تخصصی می‌تونه کسب‌وکار منو نجات بده.»

### اهداف
-  افزایش فروش از طریق کانال آنلاین
- جذب مشتریان جدید از سراسر کشور
- مدیریت بهتر موجودی انبار و سفارشات
- رقابت با فروشگاه‌های بزرگ

### دردها
-  هزینه بالای تبلیغات در شبکه‌های اجتماعی
- برگشت خوردن سفارشات به دلیل عدم آگاهی مشتری از محصول
- رقابت ناعادلانه با فروشگاه‌های بزرگ
- نداشتن پلتفرم تخصصی برای نمایش محصولات

### نیازها
-  صفحه فروشگاهی اختصاصی در سایت
- سیستم مدیریت سفارش و موجودی
- سیستم نوبت دهی آنلاین برای کلینیک
- امکان نمایش نظرات و امتیاز مشتریان

### سناریوی استفاده
> وارد سایت می‌شه و روی «ثبت‌نام پت‌شاپ‌ها» کلیک می‌کنه
> مدارک کسب‌وکار رو بارگذاری می‌کنه و منتظر تأیید می‌مونه
> بعد از تأیید، صفحه فروشگاهی اختصاصی‌اش ساخته می‌شه
> محصولات رو با عکس، قیمت، موجودی و توضیحات بارگذاری می‌کنه
> یک مشتری از شیراز سفارش میدهد

## ۵. پرسونا ۴ - کیوان احمدی (واگذار کننده پت)

### مشخصات دموگرافیک
| ویژگی | مقدار |
|--------|-------|
| نام | کیوان احمدی |
| سن | 32 سال |
| جنسیت | مرد |
| شغل | مهندس عمران |
| محل زندگی | کرج |
| تحصیلات | کارشناسی ارشد عمران |
| مهارت فنی | متوسط |

### نقل‌قول
> «راکی عضوی از خانواده‌مونه. من مجبورم واگذارش کنم، ولی می‌خوام مطمئن باشم به دست کسی می‌رسه که واقعاً دوستش داشته باشه.»

### اهداف
- پیدا کردن یک خانواده مناسب و قابل اعتماد برای پت
- اطمینان از اینکه پت به دست آدم خوبی می‌رسد
- انجام فرآیند واگذاری به صورت قانونی و امن 

### دردها
- ترس از رسیدن پت به دست افراد سودجو یا بی‌رحم
- پیدا نکردن افراد معتبر برای واگذاری
- عدم وجود نظارت بر فرآیند واگذاری
- احساس گناه و استرس شدید  

### نیازها
- سیستم احراز هویت برای متقاضیان
- فرم ارزیابی و قرارداد واگذاری
- پیگیری وضعیت پت پس از واگذاری

### سناریوی استفاده
>  وارد بخش «واگذاری پت» می‌شه
> فرم مشخصات راکی رو پر می‌کنه: نژاد، سن، وزن، رفتار، واکسن‌ها، شرایط نگهداری
> عکس و ویدیو از راکی بارگذاری می‌کنه
> شرایط واگذاری رو می‌نویسه: «فقط خانواده‌های ساکن تهران، با حیاط، دارای تجربه نگهداری سگ.»
> متقاضیان درخواست می‌دن

## ۶. پرسونا ۵ - نگار موسوی (علاقمند به یادگیری در حوضه حیوانات خانگی)

### مشخصات دموگرافیک
| ویژگی | مقدار |
|--------|-------|
| نام | نگار موسوی |
| سن | 20 سال |
| جنسیت | زن |
| شغل | دانشجو زیست شناسی |
| محل زندگی | مشهد |
| تحصیلات | دیپلم |
| مهارت فنی | متوسط |

### نقل‌قول
> «می‌خوام قبل از اینکه پت بگیرم، همه چیز رو درست یاد بگیرم. اطلاعات درست و علمی تو اینترنت فارسی خیلی کمه.»

### اهداف
- یادگیری درباره نگهداری صحیح حیوانات خانگی
- آشنایی با نژادهای مختلف و ویژگی‌هایشان
- آماده شدن برای نگهداری پت در آینده
- پیدا کردن اطلاعات علمی و معتبر

### دردها
- اطلاعات پراکنده و غیرعلمی در اینترنت
- مقالات ترجمه‌شده با کیفیت پایین
- عدم دسترسی به منابع معتبر فارسی
- تبلیغات زیاد در سایت‌های آموزشی

### نیازها
-  بخش مقالات با دسته‌بندی موضوعی
- محتوای تأییدشده توسط متخصصان
- امکان ذخیره و نشان‌گذاری مقالات
- خبرنامه و اطلاع‌رسانی محتوای جدید

### سناریوی استفاده
> از طریق گوگل وارد مقاله «نگهداری گربه برای مبتدیان» می‌شه
> مقاله رو می‌خونه و متوجه می‌شه باید ثبت‌نام کنه تا بتونه ذخیره‌اش کنه
> ثبت‌نام انجام می‌ده
> دسته‌بندی مقالات رو مرور می‌کنه: تغذیه، سلامت، رفتار، نژادها
> چند مقاله رو در لیست «خواندن بعدی» ذخیره می‌کنه

# Use Case Diagram — پت نت

## ۱. مقدمه

این دیاگرام نشان می‌دهد چه کسی (Actor) با سیستم چه کاری (Use Case) انجام می‌دهد.

## ۲. Actors

| Actor | نقش |
|-------|------|
| مشتری | خرید محصولات، رزرو نوبت دامپزشکی، ثبت آگهی واگذاری، مطالعه مقالات |
| دامپزشک | مدیریت نوبت‌ها، ثبت نسخه، نوشتن مقاله |
| ادمین | مدیریت محتوا (تایید مقالات و آگهی‌ها)، مدیریت محصولات، مدیریت کاربران |

## ۳. Use Cases

### ۳.۱ مشتری

- مشاهده محصولات پت‌شاپ
- جستجو و فیلتر محصولات
- افزودن محصول به سبد خرید
- ثبت سفارش و پرداخت
- پیگیری سفارشات
- مشاهده لیست دامپزشکان و درمانگاه‌ها
- رزرو نوبت دامپزشکی (انتخاب پت و زمان)
- ثبت آگهی واگذاری پت (یا درخواست سرپرستی)
- ارسال درخواست برای پت‌های واگذار شده
- مطالعه مقالات و ثبت کامنت

### ۳.۲ دامپزشک

- ورود به پنل دامپزشک
- تعریف زمان‌های آزاد (TimeSlot) برای رزرو
- مشاهده نوبت‌های رزرو شده
- ثبت نسخه و یادداشت پس از ویزیت
- ثبت مقاله جدید (آموزشی/پزشکی)

### ۳.۳ مدیر سیستم (Admin)

- ورود به پنل مدیریت
- بررسی و تایید/رد آگهی‌های واگذاری
- بررسی و تایید/رد مقالات
- مدیریت کاربران (مسدودسازی در صورت تخلف)
- مدیریت محصولات (افزودن، ویرایش، حذف)
- مشاهده و تغییر وضعیت سفارشات

## ۴.۱ سناریوی اصلی اول – خرید از پت‌شاپ

1. مشتری وارد صفحه محصولات پت‌شاپ می‌شود.
2. محصولات را جستجو/فیلتر می‌کند.
3. محصول مورد نظر را به سبد خرید اضافه می‌کند.
4. به صفحه سبد خرید می‌رود و آدرس ارسال را انتخاب می‌کند.
5. ثبت سفارش را می‌کند.
6. شماره پیگیری را دریافت می‌کند.

## ۴.۲ سناریوی اصلی دوم – رزرو نوبت دامپزشکی

1. مشتری وارد صفحه دامپزشکی می‌شود.
2. درمانگاه و دامپزشک مورد نظر را انتخاب می‌کند.
3. زمان‌های آزاد (TimeSlots) را مشاهده می‌کند.
4. یکی از زمان‌ها را انتخاب کرده و اطلاعات پت خود را وارد می‌کند.
5. دکمه «رزرو نوبت» را می‌زند.
6. شماره پیگیری نوبت را دریافت می‌کند.

## ۴.۳ سناریوی اصلی سوم – ثبت آگهی واگذاری پت

1. مشتری وارد بخش «واگذاری پت» می‌شود.
2. فرم آگهی (نوع واگذاری/سرپرستی، نام پت، نژاد، عکس، توضیحات) را پر می‌کند.
3. دکمه «ثبت آگهی» را می‌زند.
4. سیستم پیام «آگهی شما ثبت شد و در انتظار تایید مدیر است» را نشان می‌دهد.
5. مدیر سیستم آگهی را بررسی و تایید می‌کند.
6. آگهی برای سایر کاربران در سایت نمایش داده می‌شود

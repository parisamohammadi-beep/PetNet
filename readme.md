# PetNet Project
**پت‌نت (PetNet)** یک سامانهٔ وب برای صاحبان حیوانات خانگی است که آن‌ها را به دامپزشکان و کلینیک‌ها متصل می‌کند. کاربران می‌توانند اطلاعات دامپزشکان را ببینند، اطلاعات حیوان خود را ثبت کنند و به‌صورت آنلاین درخواست نوبت بدهند؛ کلینیک هم درخواست‌ها را تأیید و مدیریت می‌کند. در ادامه، امکاناتی مانند پروندهٔ سوابق مراجعه، پنل دامپزشک، واگذاری حیوانات و محتوای آموزشی به پروژه اضافه می‌شود.
این پروژه گروهی برای درس تحلیل و طراحی نرم افزار است.
